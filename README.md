# Game Theory Steps

An offline Android app for learning game theory at a slow, steady pace.

- **13 modules, 52 short lessons**, running from foundations through Nash equilibrium, mixed strategies, zero-sum, sequential, competition models, repeated games, incomplete information, evolutionary and cooperative games, auctions and mechanism design, to applications (tourism coopetition and education).
- **Formulas** are typeset with KaTeX. The Formulas tab collects every formula into a searchable study sheet.
- **14 interactive tools**: a payoff-matrix explorer, mixed-strategy and zero-sum charts, a backward-induction game tree, Cournot/Stackelberg charts, a repeated Prisoner's Dilemma tournament, replicator dynamics, Bayesian entry, Spence signalling, a Shapley value and core calculator, Nash bargaining, an auction simulator, and a coopetition model.
- **Quizzes** follow every lesson; a lesson is complete when every question has been answered correctly.
- **Progress tracking** covers a completion ring, a day streak, a daily goal, per-module charts, a 14-day activity chart, quiz accuracy, and a list of lessons worth reviewing.

The app's content lives in `app/src/main/assets/web`. GitHub Actions builds the APK; download it from the **Releases** page.
